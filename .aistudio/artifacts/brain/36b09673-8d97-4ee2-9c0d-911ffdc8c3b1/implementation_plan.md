## 3. Key Product Decisions & Trade-Offs

- **Decision 1: True Multi-Page Physical HTML Architecture + Express Security & Clean-URL Server**
  - *Chosen Approach*: Build and serve **37 real, standalone physical HTML5 documents** (`7` parent pages + `30` linked-company pages), paired with modular shared CSS/JS utilities and per-brand theme stylesheets, served at clean trailing-slash URLs (`/company-slug/` and `/company-slug/about/`) by a hardened Express server—plus auto-generated `_headers` and `_redirects` files for portable static hosting (such as Netlify) whenever approved.
  - *Why*: Satisfies the strict requirement that every public page is its own physical HTML file (no SPA virtual routing, no iframes, no monolithic CSS/JS bundle) while enabling real server-side security headers, rate limiting, and input validation.
  - *Alternatives Considered*: Single-page React dynamic routing was rejected because it violates the physical-HTML-per-page requirement and weakens independent crawlability.
- **Decision 2: Dual-Layer Quote Form Handling (Hardened Server Endpoint + Direct Client Handoff)**
  - *Chosen Approach*: Every quote form (on `/contact/`, parent `/`, and each linked company's Home page) submits to a rate-limited, server-validated `/api/quote` endpoint with CSRF origin verification, honeypot spam defense, and strict sanitization, then confirms receipt and offers one-click pre-filled `mailto:devintaseff4@gmail.com` and WhatsApp (`647-557-6364`) dispatch—matching the live parent website's workflow without requiring an unapproved external database.
  - *Why*: Protects against XSS, header injection, and automated bot floods while ensuring zero lost leads even before SMTP credentials or third-party CRM integrations are configured.
- **Decision 3: Canonical & Structured Data Hygiene Across Shared Domain**
  - *Chosen Approach*: Fix the parent site's broken `gtaductmasters.com` canonical/OG URLs to `https://gtaductmasters.ca/...`, generate unique `<title>`, `<meta name="description">`, canonical URLs, and Open Graph tags for all 37 HTML files, include verified `AggregateRating` (`4.9 / 347`) only on GTA Duct Masters where verified, and use factual `HVACBusiness` structured data (name, URL, verified telephone/email/hours, and core services) on linked companies without doorway-page keyword stuffing.

### Interactive Component & State Mapping

- **Responsive Navigation & Partner Directory**: Accessible `<nav>` with `aria-expanded` mobile drawer toggle, `Escape` key dismissal, active-page state indicator, and direct clean-URL links from the GTA Duct Masters Partner Directory to all 15 linked companies.
